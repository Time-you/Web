Web-дизайн — це створення та оформлення веб-сторінок. Для розробки сайтів використовують мову HTML, таблиці стилів CSS та мову JavaScript. HTML визначає структуру сторінки, CSS відповідає за зовнішній вигляд, а JavaScript додає інтерактивність.

Цей сайт створено як приклад використання фреймової структури в HTML. Меню розташоване ліворуч, а зміст відкривається у правому фреймі.
